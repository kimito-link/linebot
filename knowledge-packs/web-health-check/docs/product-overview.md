# WEBサイト健康診断 — 製品概要

## これは何か

ドメイン・会社名・人名を入れると、**検索での評判**と**サイトの安全性**を
約1分で確認できる無料ツール。アカウント登録・アプリ内課金は無い。

LP: https://web-health-check.link/

## 入手先（4つ・すべて無料）

|---|---|

| iPhone / iPad | App Store |

Chrome 拡張は右クリック診断・過去レポートとの差分比較ができるため、
毎月の定点観測に向く。

## 診断できること

### 検索まわり
- 検索候補（Google / Yahoo! / Bing）にネガティブな語が出ていないか
- 関連キーワード（a〜z 拡張）
- 検索結果1ページ目
- 社名を載せている第三者サイト

### 書いている側を調べる
- WHOIS / RDAP でドメインの登録情報（いつ作られたか、どこで登録されたか）
- DNS・IP・メール設定から運用元の推定
- Wayback Machine で過去のページ

※ `.com` などは制度上、登録者名が伏せられているのが一般的。
　 `.jp` は組織名が公開されている場合がある。**必ず判明するとは言わない。**

### 技術面
- SSL 証明書・ドメイン期限
- なりすましメール対策（SPF / DKIM / DMARC）
- WordPress / PHP の脆弱性、Mixed Content
- サイトマップ・メタタグ・OGP・インデックス数

結果はすべて「**健全 / 注意 / 要対応**」の3段階で表示する。

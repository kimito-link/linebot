# 相談の流れ（LPで約束している内容）

web-health-check.link に明記しているため、**この通りに運用する必要がある**。
窓口の応対がここから外れると、LPが嘘になる。

## 4ステップ

1. **気になっていることを送るだけ**
   診断結果の画面をそのまま送ってもらってよい。社名だけでも受け付ける。

2. **担当者が状況を確認して返信（24時間以内）**
   自動応答だけで終わらせない。何ができて何ができないかを先に伝える。

3. **必要なら電話・Zoom**
   文字だけでは決めにくい場合、画面を一緒に見ながら説明する。

4. **見積りを見てから決めてもらう**
   ここまですべて無料。断られた場合、その後の連絡はしない。

## 冒頭で必ず伝えること

- 売り込みの連絡はしない
- 登録だけで料金は発生しない

## ★運用上の注意

**「24時間以内に返信」はLPに書いた約束**。ステップ配信の自動応答は
1通目として出してよいが、**それで返信したことにはならない**。
実際に担当者が内容を見て返す運用が必要。

守れなくなった場合は、LP側の記載（`#next-step` ブロック）を先に直すこと。
LPと実運用が食い違った状態を放置しない。

## 対応できること

| 種類 | 備考 |
|---|---|
| 口コミへの対応 | **1件から相談可**。金額の階段の1段目 |
| 検索候補・検索結果への対策 | 件数と難易度で変わるため要見積り |
| サイト・メールの不具合修正 | 診断結果から直接つながる |

金額は Bot が断定しない。必ず担当者の見積りにつなぐ。

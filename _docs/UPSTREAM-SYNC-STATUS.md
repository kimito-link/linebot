## `upstream/update-*` ブランチについて

workflow が毎晩作る。**上流をmainにマージするまで作られ続ける**のが正常
（重複生成は防いであるので、既にあるうちは増えない）。

精査済みなので、**次に見るときは差分だけ見ればよい**:

```bash
git fetch origin 'refs/heads/upstream/*:refs/remotes/origin/upstream/*'
# 前回の精査時点（8b81bbc）以降に上流で何が増えたか
git log --oneline 8b81bbc..origin/upstream/update-<最新> --no-merges
```

`8b81bbc` が 2026-08-31 に精査した時点。ここまでは見終えている。

**増えていなければブランチは消してよい**（次のcronでまた作られる）。
